-- Bitwise Operators --
&   AND         -> 1 only if both bits are 1
|   OR          -> 1 if at least one bit is 1
^   XOR         -> 1 if bits are different
~   NOT         -> Inverts all bits
<<  Left Shift  -> Multiplies by 2
>>  Right Shift -> Divides by 2

==============================
✅ MOST IMPORTANT BIT TRICKS
==============================

1. Check if number is odd
   (n & 1) == 1

2. Multiply by 2
   n << 1

3. Divide by 2
   n >> 1

4. Check if power of 2
   n > 0 && (n & (n - 1)) == 0

5. Count set bits (1s)
   Integer.bitCount(n)

6. Remove lowest set bit
   n & (n - 1)

7. Isolate lowest set bit
   n & -n

8. Set the ith bit
   n | (1 << i)

9. Clear the ith bit
   n & ~(1 << i)

10. Toggle the ith bit
    n ^ (1 << i)

11. Check if ith bit is set
    (n & (1 << i)) != 0

12. Swap two numbers (no temp)
    a ^= b; b ^= a; a ^= b;

13. Turn off rightmost set bit
    n & (n - 1)

14. Right propagate rightmost set bit
    n | (n - 1)

15. Isolate rightmost 0
    ~n & (n + 1)

16. Turn on rightmost 0
    n | (n + 1)

17. Find log base 2
    (int)(Math.log(n) / Math.log(2))

18. Check if only one bit is set
    n != 0 && (n & (n - 1)) == 0

19. Total subsets of n elements
    (1 << n)

20. Iterate all subsets using bitmask
    for (int mask = 0; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) {
                // element i is included
            }
        }
    }

21. Convert binary (as int array or string) to decimal
    // For int[] arr (MSB at index 0):
    int ans = 0;
    for (int bit : arr) {
        ans = (ans << 1) | bit;
    }
    // For String s (e.g., "1011"):
    int ans = Integer.parseInt(s, 2);
